# Print post-linkage diagnostics

Print post-linkage diagnostics

## Usage

``` r
# S3 method for class 'RL_diagnostics'
print(x, threshold = 0.5, ...)
```

## Arguments

- x:

  An `RL_diagnostics` object, see
  [`RL_diagnostics()`](rl_diagnostics.md).

- threshold:

  Numeric, the linkage decision rule at which the measures are displayed
  (default `0.5`).

- ...:

  Ignored.

## Value

`x`, invisibly; called for its printing side effect.
